# Community Science Museum - Semester Project 1

This project is a website for a Community Science Museum. It provides information about exhibitions, what to explore at the museum, upcoming events, and practical information for visitors. The website is built using only HTML and CSS and is hosted on GitHub Pages.

## Features

- Information about museum exhibitions
- Overview of interactive areas and exploration zones
- Event listings and museum activities
- Visitor information (opening hours, location, etc.)
- Responsive layout for different screen sizes
- Clean and structured user interface

## Technologies

- HTML
- CSS
- GitHub Pages (hosting)

## Getting Started
To view the Project:
- Open the live website on GitHub Pages
- Download the project and open index.html
  
## Purpose

This project was created as part of a school assignment focusing on layout, structure, and basic UX design using HTML and CSS.
